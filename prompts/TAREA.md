# Tarea: Mi prompt profesional

## Funcionalidad elegida
Sistema de Registro y Gestión de Alumnos en Java Swing.

---

## Version 1: prompt basico
```text
Hazme un codigo para registrar alumnos en Java.
```
## version 2: 
```text 
Actua como desarrollador Java. Crea un programa con interfaz grafica Swing para registrar alumnos con nombre, codigo y carrera. Muestra los datos en una lista y explica el codigo.
```
## version 3: prompt final 
```text 
Actua como desarrollador Java Senior. Crea un modulo de escritorio en Java Swing para el registro de alumnos en un sistema academico universitario. 

El usuario debe ingresar: Nombre completo, Codigo de estudiante (8 digitos) y Carrera.

Restricciones:
- No uses librerias externas (solo componentes nativos de java.desktop).
- Valida que el codigo sea estrictamente numerico y tenga 8 digitos.
- Muestra mensajes de error o exito usando JOptionPane.

Presenta primero una breve explicacion de la arquitectura utilizada (clases) y luego el codigo fuente completo y comentado en un solo bloque.
```

## Componentes del prompt final

| Componente | Texto de mi prompt final |
|---|---|
| **Rol** | Actua como desarrollador Java Senior. |
| **Instruccion** | Crea un modulo de escritorio en Java Swing para el registro de alumnos... |
| **Contexto** | ...en un sistema academico universitario. El usuario debe ingresar: Nombre completo, Codigo de estudiante (8 digitos) y Carrera. |
| **Ejemplo / Restricciones** | Restricciones: No uses librerias externas, valida que el codigo sea estrictamente numerico y tenga 8 digitos, usa JOptionPane. |
| **Formato** | Presenta primero una breve explicacion de la arquitectura utilizada (clases) y luego el codigo fuente completo y comentado. |
